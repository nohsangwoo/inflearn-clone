# 로컬 개발 데이터 모드

공개 홈과 강의 상세는 기본적으로 저장소의 운영 예시 데이터를 사용합니다. 따라서 Neon 연결이 없거나 비밀번호가 만료되어도 디자인, 검색, 모집 상태, 커리큘럼, 후기 페이지네이션을 바로 확인할 수 있습니다.

관리자, 실제 로그인 사용자, 신청·구매·정산처럼 영속 데이터가 필요한 기능은 유효한 PostgreSQL 연결이 필요합니다.

## 실제 개발 DB 사용

Neon에서 새 연결 문자열을 발급하고 `.env`의 `DATABASE_URL`, `DIRECT_URL`을 갱신한 뒤 다음 값을 추가합니다.

```bash
DEV_USE_LIVE_DATABASE=true
```

그 다음 스키마와 개발 서버를 갱신합니다.

```bash
pnpm db:migrate
pnpm dev
```

`DEV_USE_LIVE_DATABASE`는 개발 모드에서만 적용됩니다. 프로덕션은 항상 실제 데이터베이스를 사용하며, 연결 실패를 예시 데이터로 숨기지 않습니다.
